# ПРОМГАЗ

Первая версия сайта для согласования: главная, каталог из восьми газов, услуги, информация о компании, партнёр и контакты.

## Устройство проекта

- dist/index.html — главная страница.
- dist/gases/ — отдельные страницы газов.
- dist/assets/styles.css — оформление и мобильная версия.
- dist/assets/site.js — меню и подготовка запроса по электронной почте.
- content/catalog.json — содержание каталога.
- scripts/generate.py — генерация страниц из согласованных текстов.
- .github/workflows/pages.yml — публикация dist через GitHub Pages.

Сайт работает как обычный статический HTML. Установка библиотек не требуется.
После изменения каталога или текстов в генераторе выполните: python scripts/generate.py.
CSS и JavaScript редактируются непосредственно в dist/assets.

## Запросы покупателей

Кнопка «Запросить стоимость» открывает окно с составом заказа. Кнопка «Открыть письмо»
подготавливает письмо на Promgaz21@yandex.ru в почтовой программе посетителя.
Посетитель самостоятельно отправляет письмо. Сайт не сообщает об отправке и
не сохраняет обращения. Все телефоны открываются как ссылки для звонка.

## GitHub Pages

1. Создать репозиторий и загрузить проект.
2. В Settings → Pages выбрать Source: GitHub Actions.
3. Публикация запускается при изменениях ветки main. Её можно запустить вручную
   во вкладке Actions через workflow «Publish Promgaz website».

GitHub Pages должен быть доступен для выбранной видимости репозитория и тарифа.
Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Что сверить перед запуском продаж

- Собственный прайс: ассортимент, марки газов, тара, единицы расчёта и цены.
- Доступность заправки, обмена, аренды, ремонта и освидетельствования.
- География, стоимость и сроки доставки; часы работы.
- Основной телефон для заявок.
- Полное ФИО и ОГРНИП продавца.
- Согласованная с Линде Газ Рус формулировка партнёрства и актуальный прайс партнёра.

Ассортимент и услуги в этой версии предварительные: ориентир — материалы,
переданные заказчиком, включая прайс ТехноГаза. Цены конкурента не используются.
Медицинские газы, обещания круглосуточной доставки, собственное производство,
сертификаты и гарантии наличия на сайт не добавлены.

## Предпросмотр

На всех страницах стоит noindex, nofollow, в robots.txt запрещена индексация:
это версия для согласования. После подтверждения содержания для поискового запуска
нужно снять эти ограничения в генераторе и robots.txt и добавить адрес основного домена.

Фотография фасада передана заказчиком. Исходный файл сохранён без изменений;
интерфейс телефона скрыт кадрированием при отображении на странице.
